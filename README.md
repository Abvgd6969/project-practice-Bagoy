## Описание

В репозитории собраны материалы по проектно-технологической практике. В качестве объекта анализа выбран маркетплейс Ozon. Основной процесс для моделирования — **«Обработка заказа клиента на маркетплейсе Ozon»**.

В работе представлены аналитическая записка, конспекты по BPMN 2.0 и IDEF0, диаграммы в формате draw.io и Python-файлы с упражнениями по базовому экономическому анализу.
